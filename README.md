## 01 / PROFILE

关注嵌入式系统、智能硬件与电子电路，喜欢把课程设计和实验原型继续整理成可运行、可复现的开源作品。

- **SYSTEM** — 从传感器采集、任务调度到设备控制与多端交互
- **HARDWARE** — 关注供电、接口、执行器、显示与真实硬件稳定性
- **DELIVERY** — 保留接线说明、GPIO 映射、测试边界和调试记录
